The bundled academic school directory contains factual interoperability metadata
(school name, public academic-system entry URL, and system-family label) observed
in WakeUp Schedule 6.1.20 on 2026-09-02:
https://www.wakeup.fun/
Directory versionTimeLine: 1763017986

No WakeUp implementation code, credentials, cookies, or timetable responses are
included. CourseSchedule independently implements its parsers. Entries that depend
on a private/school-specific adapter remain visible as "adapter required" instead
of being presented as functional. Numeric IP addresses, private-network hosts,
malformed URLs, credentials, query tickets, fragments, and session IDs are excluded.
Legacy HTTP directory entries require an explicit warning confirmation in the app.
Subsequent HTTP and HTTPS navigation is handled by the academic-import WebView
without a school-domain allowlist.

The optional "referenceUrl" field on some "adapter required" entries repeats the
public entry address WakeUp recorded for that school (which may be a campus-IP or
WebVPN address). It is displayed as guidance text only and is never loaded or
trusted by the app; users must paste their own address, which passes the normal
generic-import validation.

Per-school "operation guidance" strings shown during import are short factual
navigation steps (menu and page names) adapted in CourseSchedule's own wording
from WakeUp's published import instructions for those schools.
