# 待办页面、导航对齐与触感 · 1.0.25

录屏中的上下跳来自导航尺寸不一致：待办页原为 68dp，其他三页为 72dp；选中背景也分别为 52×32dp 和 58×34dp。现在四页统一为 72dp，选中背景为 58×34dp，图标为 22dp，文字为 11sp。选中和未选中的字级一致，切换不会改变导航的布局位置。

## 动效与界面

- 导航图标在 150ms 内轻抬 4dp，再用 250ms 回到原位；文字和背景保持固定。快速重复点击会重置当前动画，位移不累积。
- 页面名称统一为「待办」，新增与编辑使用「新建待办」「编辑待办」。卡片间距和字级收紧，选中分类通过柔和背景表示，空状态有明确标题和说明。
- 待办首次进入用 8dp 的短距离淡入；切换分类用 6dp、240ms 的过渡。搜索输入直接刷新结果。
- 日期、时间、课程和提醒区块用 200ms 的边界与淡入淡出过渡展开。编辑页顶部保存和取消保持固定。
- 勾选后先完成数据库写入，再保留短暂的勾选状态并淡出。写入失败会恢复列表，不发出成功触感。
- 从待办返回课表使用已有的课程卡片进入动效。系统关闭动画时直接呈现最终状态。

## 触感

已移除导航、分类、事项类型、日历、月份、课程、提醒、新建、保存和删除的触感。只有手动滚动时间刻度和成功完成事项保留反馈，重新打开事项不震动。

Android 14 及以上：小时使用 `SEGMENT_TICK`；分钟使用更柔和的 `SEGMENT_FREQUENT_TICK`；完成事项使用 `TOGGLE_ON`。分钟刻度按 40ms、小时按 60ms 节流，快速滚动不会叠加振动。旧系统的时间刻度使用 `CLOCK_TICK`；完成反馈仅在支持对应系统 API 时提供。调用 `View.performHapticFeedback`，没有强制振动或额外权限，遵循系统触感设置。

参考 [Android 触感常量](https://developer.android.com/reference/android/view/HapticFeedbackConstants#SEGMENT_FREQUENT_TICK)和[触感事件设计](https://developer.android.com/develop/ui/views/haptics/haptic-feedback)。模拟器可以验证触发路径与视觉动效，马达强度和手感仍需在实际手机上体验。
