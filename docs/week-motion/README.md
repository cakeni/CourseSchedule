# 课程切周动效 · 1.0.35

设置入口：**设置 → 课表显示 → 课程切周动效**。选择立即保存，返回课表生效，并随备份保存。旧备份没有此选项时采用默认方案。

## 轻层滑页（默认）

日期与整周课程整体移动，时间轴和底部导航保持固定参照。过渡带最多 1.8% 的缩放、12% 的透明度变化和 12dp 页间距离，落地后恢复原尺寸与颜色。原生 ViewPager2 驱动手势，随时可以反向取消。相邻周的纵向滚动位置不同，也会在切换过程中与同一时间轴对齐，落地后保留目标周的滚动位置。

## 位置接续（可选）

相同课程保持位置关系，有变化的课程移动到新时段，其余课程原位进出。课程匹配优先使用 ID；不同 ID 的同名同教师课程，仅在对应关系明确时接续。非本周课程的灰色状态、颜色和教室变化也连续过渡。

视图回收重新挂载时依据有效绘制尺寸启用过渡，避免第二轮整学期滑动退回普通整页移动。

## 月份与星期日期栏

两种方案都保留月份、星期和日期各列的轻抬落位：6dp 位移、0.72→1 透明度，每列 240ms、错峰 14ms，方向跟随左右切周。1.0.35 修复了默认方案漏播月份栏动效的问题。

![原生月份栏录屏](months.gif)

系统关闭动画时取消缩放、淡入与栏内落位动效；手动滑动保留空间导航，箭头切周立即完成。设置页项目公告的按压高光也已恢复。

## 验证与参考

单元检查覆盖课程匹配、可反向的面板变换、文字过渡及默认设置兼容。原生设备检查覆盖浅色、深色、关闭动画、左右滑动、箭头切周、取消、空课表、设置切换、纵向滚动与整学期往返。月份栏检查明确记录每次切换的移动帧并核对最终位置和透明度。

设计参考 [Apple · Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/) 与 [Motion · Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/motion) 中关于即时响应、允许取消和克制重复装饰的原则，按课表空间关系实现。
