# 课程编辑页触感 · 1.0.28

本次为添加 / 编辑课程页面补充有操作含义的触感，沿用已有布局和动效。

## 触发规则

| 操作 | 反馈 |
| --- | --- |
| 改变星期、单双周、课程颜色、提醒选项 | 一次原生选项轻反馈 |
| 节次、周次滚轮跨过刻度 | 原生细刻度反馈；Android 14 及以上间隔至少 90 ms，更早系统至少 140 ms |
| 保存或删除实际成功 | 一次原生确认反馈 |
| 展开 / 收起面板、完成选择、返回、重复点已选项 | 无额外触感 |
| 初始加载、旋转恢复、自动联动另一端范围、校验失败 | 无额外触感 |

使用 View.performHapticFeedback 的系统语义，不使用自定义长震动或绕过系统开关的标志。滚轮自带反馈禁用后，由页面统一发送刻度反馈，避免叠加；四个滚轮共用节流。成功确认由 ViewModel 记录消费状态，避免生命周期恢复时再次反馈。

## 验证

- Debug APK 和 instrumentation APK 构建成功。
- 原生课程编辑页回归 7 项通过：旋转恢复、冲突重试、学期变化拦截、滚轮范围联动、未保存退出、名称校验及删除确认、键盘与固定保存区。
- 单元测试 192 项：191 通过，1 跳过，0 失败 / 错误。
- Lint 0 错误，218 警告，1 提示；数量与上个版本一致。
- 模拟器 API 35 已安装新版本，系统触感设置未改变。
- 模拟器不能判断实体马达的触感强弱，真机手感尚未验证。
