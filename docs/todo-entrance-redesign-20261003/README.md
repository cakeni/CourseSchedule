# 待办首帧与进入动效 · 1.0.30

从课表、导入或设置切到待办时，原页面会先绘制零计数和空列表，再刷新真实数据；整页淡入也会造成明显的亮度变化。现在首帧等待学期和待办数据就绪，标题、统计卡片、搜索区及列表分层进入，背景和底部导航保持固定。

标题从8dp的偏移开始；三张统计卡片分别延迟30、60、90ms，从20dp的偏移回到原位；搜索和列表随后进入，总时长约510ms。所有层的透明度逐步增加，不重复启动整页淡入。统计卡片的文字和圆角在移动过程中完整保留。

点击分类、刷新数据或离开页面时，进入动画会取消并恢复各层状态。旋转及从编辑页返回不重播；系统关闭动画时直接显示最终状态。数据库、备份及提醒规则不变。

- 浅色和深色分别采样五次进入，未发现占位内容绘制、透明度回退、动画重启或导航偏移。
