# 添加 / 编辑课程页重设计

本次范围仅为课程编辑页，包含从课表和课程助手打开的添加、编辑入口。

## 信息布局

- 标题与学期固定在上方，课程名称使用清晰的主标题输入；教师和地点保留独立标签。
- 星期在一行内直接选择。节次和周次先显示摘要，点击后原位展开开始、结束滚轮；节次同时显示设置中的实际时间。
- 颜色使用六列小色块，提醒采用两列文字选项。备注与这些设置归于同一组。
- 底部固定上课安排摘要与保存按钮，键盘弹出时随可用区域调整；删除课程仍需确认。

## 动效

- 初次进入：内容淡入并移动 6 dp，260 ms；标题和保存入口固定。
- 星期、周类型：选中短线滑动 220 ms，图标不弹跳。
- 展开与收起：尺寸变化 220 ms、选项淡入淡出 160 ms，箭头同步转向。展开后只在选项超出视区时平滑滚动。
- 颜色：预览与课程标记用 200 ms 过渡。
- 延续现有轻微按压缩放，没有加入灰色波纹和通用震动。系统关闭动画时直接呈现最终状态。

## 行为与数据

- 保留快捷添加的星期、节次范围、当前周次，以及编辑、删除、课程冲突检查和提醒。
- 开始和结束范围始终有序，旋转或系统恢复保留填写内容、选择与展开状态。
- 编辑时保留原有颜色编码、非预设的提醒分钟数与创建时间。
- 保存操作通过 ViewModel 跨旋转保留，重复点击不会重复写入；冲突检查与写入位于同一个 Room 事务。
- 当前学期或原课程发生变化时拒绝过期写入，并保留页面内容供查看；离开未保存页面可选择继续编辑。
- 提醒安排失败与课程保存失败分开处理，避免已经入库后再次插入。

验证记录和实际运行截图位于同名 outputs、analysis 目录；最终结果以 validation.json 为准。
