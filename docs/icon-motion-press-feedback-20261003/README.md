# 导航动效与交互反馈

版本：1.0.26（versionCode 27）。

四个底部图标保留原来的轮廓，并各自表达对应动作。动画仅作用于矢量内部，导航栏、图标容器和文字的位置不随动画移动。

| 入口 | 动作 | 时长 |
| --- | --- | --- |
| 课表 | 外框固定，内部日期沿上缘折叠、展开 | 680 ms |
| 待办 | 逐笔绘制勾选，再绘制下划线 | 590 ms |
| 导入课程 | 底座固定，箭头蓄力、推进、收定 | 700 ms |
| 设置 | 齿轮转过一格，轻微回收角度后停稳 | 700 ms |

快速重复点击会停止上一段动画，并从完整的新序列开始。结束后恢复原始静态图标和当前页面的选中颜色。系统关闭动画时直接显示静态图标。

按压反馈使用原生 StateListAnimator：图标轻微缩至 94%，按钮约 97.5%，长行约 99.2%，110 ms 收缩、220 ms 回到原位。滚动取消、禁用和松开均由控件状态处理，不占用触摸监听器。触摸时不绘制灰色或彩色波纹；键盘焦点仍有对应页面色的提示。未增加点击震动。

常驻装饰也做了精简：移除课表、待办空状态图标的底色容器；移除四页底栏的选中胶囊和外边框；移除菜单、导入入口和设置入口的图标色块。课表空状态使用线性日历、辅助说明和轻量添加入口；课程助手菜单降低阴影并去掉描边。页面原有配色保留。

关键实现：

- `ViewMotion.kt`：状态按压、矢量动效播放、重复点击处理、底栏指示器设置。
- `avd_nav_*.xml`、`nav_*_parts.xml`、`animator/nav_*.xml`：四个图标的独立动效。
- `interaction_styles.xml`、`control_focus*.xml`：控件反馈与键盘焦点。
- `item_week_schedule.xml`、`popup_course_tools.xml`、`bg_bottom_navigation.xml`：空状态、菜单与底栏。

验收结果和 APK 校验值见 `outputs/icon-motion-press-feedback-20261003/validation.json`。预览图及动画来自模拟器实际截图、录屏，没有绘制替代界面。
