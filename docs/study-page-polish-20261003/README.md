# 学习事项独立页面 · 1.0.24

学习事项成为底部导航的「学习」页面，从课表、导入、设置都可以直接进入。列表用于安排和勾选事项；新增、编辑使用独立全屏页面，顶部固定取消和保存。

## 页面与交互

- 「今天」「7 天内」「全部」显示待办数量，点击切换列表。「今天」包含逾期事项，标题注明「今天与逾期」；7 天内按当前时间过滤未来截止。
- 事项按已逾期、今天、明天、未来 7 天、稍后分组。每行突出标题，下方展示课程与截止时间；类型缩成小标签，左侧直接完成。
- 已完成数量放在列表标题右侧，可以查看和重新打开。搜索匹配标题和课程，筛选状态在旋转屏幕后保留。
- 新建事项固定在独立的底部操作栏，列表在操作栏上方滚动，按钮不遮挡任何一行。提醒设置放在标题旁，只有权限或总开关有问题时展示提示。
- 编辑页收紧标题和字段间距；事项类型直接选择。日期和时间在当前页面展开，提供今天、明天、20:00、23:59 快捷选择，同时保留任意日期和分钟选择。新建事项必须明确选择日期和时间。
- 选项实际变化时使用轻微触感，完成、保存、删除成功后使用确认触感。滚轮反馈做节流；调用系统 `View.performHapticFeedback`，遵循系统触感设置，没有新增振动权限。模拟器可以验证交互路径，实际振动强度仍由真机和系统决定。
- 保留草稿旋转恢复、过期编辑保护、删除与放弃修改的页面内确认、提醒取消和恢复逻辑。

## 设计参考

分类数量和直接勾选参考 [Apple 提醒事项](https://support.apple.com/guide/iphone/organize-multiple-lists-iph2c6cf708e/ios)，按移动端的任务层级重新组织。触感采用 [Android 触感原则](https://developer.android.com/develop/ui/views/haptics/haptics-principles)和 [View 触感 API](https://developer.android.com/develop/ui/views/haptics/haptic-feedback)。学习页面使用独立主题：浅色白底，今天橙色、近期绿色、主操作蓝色；深色使用相应的柔和色调。选中分类用边框和背景共同表示。其他页面沿用原配色。
