# 课程助手：会话布局与操作完善

助手页面采用独立的黑白灰主题，课表、导入及常规设置页面保持原有主题。首页、聊天、输入区、确认卡片、候选选择与常用指令面板统一字体层次、圆角和细线图标。

左上角打开历史记录，支持日期分组、本学期标题与消息搜索、结果定位。新建对话位于右上角及抽屉内；服务配置、提醒和返回课表位于抽屉底部；撤销入口跟随执行回执。键盘弹出时收起空白页欢迎区和搜索抽屉的设置区，小屏仍可输入、搜索及确认课程操作。

同时补齐本地日期与空闲节次计算、单次课程调整、条件查询、查询结果详情、冲突备选及同名目标选择。待确认方案可继续修正，失败重试保留原请求日期。课程操作仍须明确确认，并进行本地目标、重复、冲突和过期校验。

本地验证：176 项单元测试、26 项助手交互测试、360 × 640 dp 小屏 3 项测试通过。强制停止后的状态恢复在本轮功能回归中通过，Lint 0 错误、156 警告。Debug 构建及安装成功。发布前另外检查提交快照的干净构建，结果见对应 PR 的检查记录。

DeepSeek 真实客户端请求使用虚构课程与固定日期，最后一轮 13 条指令均通过，没有写入真实课表。早期回归发现星期编号、目标查询字段和已选目标状态的问题，补充协议示例与状态约束后复测通过。固定小样本结果不代表全部自然语言输入的准确率。密钥与本机配置未进入提交。
