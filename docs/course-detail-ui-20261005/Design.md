# 课程详情的柔和渐变方案

日间保留课程原色，背景从原色缓慢过渡到同色系的浅色。课程换色与恢复草稿时，背景仍同步使用所选颜色。信息卡使用接近白色的轻微半透明填充，去掉描边；标签用较轻的字色，主要信息保持深色文字。

夜间保留黑色基底，只增加很弱的中性明暗渐变。信息区使用无描边的深灰填充，不叠加课程色光晕。保存操作采用日间深色、夜间浅色胶囊，使页面只有一个明确的主要操作。

真实课表背景经过一次去色模糊再淡入，文字、输入框和按钮不参与模糊。只保留一个线性渐变，没有反光纹理或多层彩色光斑，滚动边缘不增加渐隐。

原位编辑、键盘避让、保存/删除及课程块展开收回动效保留。课程块配色、非本周和公告页沿用前版。本轮只调整课程详情的材质和视觉层次。
