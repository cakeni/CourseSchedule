# 课程导入说明

晴课表会先解析并预览文件，不会在选择文件后立即覆盖数据。预览会标出可导入项、时间冲突、重复项、无效项，以及教师和地点字段完整度。

## Excel `.xlsx`

推荐使用一行一门课的结构化表格。表头可使用下面的中文或对应英文名称：

| 字段 | 示例 | 必需 |
| --- | --- | --- |
| 课程名称 | 数据结构 | 是 |
| 教师 | 张老师 | 否 |
| 教室 | 博学楼 A508 | 否 |
| 星期 | 周三 | 是 |
| 开始节次 | 1 | 是 |
| 结束节次 | 2 | 否，默认等于开始节次 |
| 开始周 | 1 | 否 |
| 结束周 | 16 | 否 |
| 单双周 | 每周 / 单周 / 双周 | 否 |

也支持部分高校导出的周课表网格，解析器会识别星期列、节次行、课程代码、非连续周次和地点。

注意事项：

- 旧版 `.xls` 不受支持，请先另存为 `.xlsx`。
- 学校导出文件中没有教师字段时，应用无法推断教师姓名；预览会显示教师完整度为 `0/N`。
- 文件中的非连续周次会拆成多条排课记录，以保证每周显示正确。

## CSV

推荐保存为 UTF-8。示例：

```csv
课程名称,教师,教室,星期,开始节次,结束节次,开始周,结束周,单双周
数据结构,张老师,A101,周三,1,2,1,16,每周
大学英语,李老师,B205,周五,3,4,1,16,单周
```

## 文本

文本导入支持逗号、制表符或竖线分隔。至少需要课程名称、星期和节次，例如：

```text
数据结构 | 周三 | 1-2节 | 1-16周
```

包含教师和地点时，按完整字段顺序填写：

```text
数据结构 | 张老师 | A101 | 周三 | 1-2节 | 1-16周
```

## JSON 备份

设置页导出的完整备份包含：

- 当前学期名称、起始日期和总周数
- 当前学期课程
- 课表显示与提醒设置

恢复备份前会显示预览，并允许选择是否同时恢复学期和应用设置。

## 隐私建议

提交导入问题时，请先复制出能够复现问题的最小样例，并删除姓名、学号、班级、手机号和不相关课程信息。不要在公开 Issue 中上传真实课程表。
