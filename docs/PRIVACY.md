# 隐私说明

CourseSchedule 是本地优先的开源应用。

## 数据处理

- 课程、教师、地点、学期和提醒设置保存在设备本地的 Room 数据库与 SharedPreferences 中。
- 应用没有声明 `INTERNET` 权限，不会主动把课程数据发送到自建服务器。
- 应用不包含广告、遥测或第三方统计 SDK。
- 导入使用 Android 系统文件选择器，应用只读取用户明确选择的文件。
- 导出的 JSON 备份由用户选择保存位置，内容可能包含完整课程信息，请自行妥善保管。

## Android 系统备份

应用允许 Android 的系统备份和设备迁移功能备份数据库与偏好设置。是否上传到设备厂商或系统账户的云端由 Android 系统和用户的设备设置决定，而不是由 CourseSchedule 自行上传。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| 通知 | 显示课前提醒 |
| 精确闹钟 | 尽量按设定时间触发提醒 |
| 开机完成 | 设备重启后恢复已启用的提醒 |
| 振动 | 提醒到达时提供振动反馈 |

应用不请求传统的存储读写权限。

## 开源构建

发布者提供的 APK 与用户自行从源码构建的 APK 可能使用不同签名。需要验证行为时，可审查 `AndroidManifest.xml`、依赖列表和对应版本源码后自行构建。
