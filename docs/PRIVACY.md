# 隐私说明

晴课表是本地优先的开源应用。

## 数据处理

- 课程、教师、地点、学期和提醒设置保存在设备本地的 Room 数据库与 SharedPreferences 中。
- 教务网页仅在用户主动选择“从教务系统导入”时访问；课表响应默认在设备本地解析，不发送到项目自建服务器。
- 教务账号和密码只提交给学校网页，应用不保存表单、Cookie、localStorage 或 sessionStorage。
- 当本地解析失败时，用户可以主动选择 AI 识别兜底并自行输入 DeepSeek 或 OpenAI API Key。应用只将可信课表页中筛选出的可见课表表格文字直接发送给所选服务商，不发送 Cookie、密码、表单值、URL、脚本或完整 HTML。
- 教务网页识别的 API Key 默认仅在本次识别期间保存在内存中；选择记住密钥时，使用 Android Keystore 加密保存在不参与系统备份与迁移的目录，可随时清除。密钥不写入数据库、SharedPreferences 或日志；结果会在写入前显示预览，由用户确认。
- 用户在“课程助手”页面主动发送消息时，对话内容、学期总周数、学期开始日期、当前日期、当前及查看周次、节次起止时间，以及本学期课程编号、名称、教师、地点、节次、周次、备注和提醒设置会直接发送到用户配置的 HTTPS API，用于理解查询和管理课程的请求。其他学期课程不会发送。页面常驻提示和 API 配置说明会注明这个数据范围。
- 新增通过本地校验后自动保存；修改和删除先在本机显示具体课程和更改内容，用户确认后才执行。操作会校验目标所属学期、是否被其他页面修改、重复和冲突，失败时整批拒绝。新增、修改、删除均支持撤销本对话最近一次成功操作；撤销也会检查是否覆盖后续更改。
- 聊天、消息时间、待确认方案、实际执行结果、失败重试信息和本对话最近一次撤销所需的课程快照保存在本地 Room 数据库中，草稿与选中对话保存在 SharedPreferences 中。按学期区分对话，退出或重启后可恢复；重启不会自动重发消息或执行方案，过期方案会被取消。可从助手菜单删除当前对话，删除聊天不删除已保存的课程；删除学期同时删除该学期聊天数据库记录，助手再次打开时清理对应草稿。课程 JSON 备份不包含这些聊天数据，Android 系统备份可能包含本地数据库和偏好设置。
- 每次发送仅使用当前对话近期上下文，不会把其他对话或其他学期的聊天一并发送。完整聊天仍可从本地历史记录查看。
- 聊天密钥默认仅在本次页面内存中使用。可选的“在本机加密保存”使用 Android Keystore 的设备密钥加密，并将配置存放在不参与系统备份与迁移的目录；配置可随时清除。配置密钥不写入聊天记录。第三方服务商的计费和数据处理规则由对应账号与服务条款决定。
- 应用不包含广告、遥测或第三方统计 SDK。
- 导入使用 Android 系统文件选择器，应用只读取用户明确选择的文件。
- 导出的 JSON 备份由用户选择保存位置，内容可能包含完整课程信息，请自行妥善保管。

## Android 系统备份

应用允许 Android 的系统备份和设备迁移功能备份数据库与偏好设置。是否上传到设备厂商或系统账户的云端由 Android 系统和用户的设备设置决定，而不是由晴课表自行上传。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| 网络 | 用户主动从学校教务网页导入课程、使用所选服务商兜底识别，或发送课程助手消息 |
| 通知 | 显示课前提醒 |
| 精确闹钟 | 尽量按设定时间触发提醒 |
| 开机完成 | 设备重启后恢复已启用的提醒 |
| 振动 | 提醒到达时提供振动反馈 |

应用不请求传统的存储读写权限。

## 开源构建

发布者提供的 APK 与用户自行从源码构建的 APK 可能使用不同签名。需要验证行为时，可审查 `AndroidManifest.xml`、依赖列表和对应版本源码后自行构建。
