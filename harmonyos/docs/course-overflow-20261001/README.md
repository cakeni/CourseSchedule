# 课表卡片文字溢出修复

## 修改

原课程名最多显示 7 行，未给教室和教师预留空间。七列布局下，长名称及“非本周”标记会把后续文字挤出固定高度的卡片。

课程名现在使用 ArkUI 的 `flexShrink(1)` 和 `LAYOUT_CONSTRAINT_FIRST`：空间不足时缩小字号，最低 9；仍放不下时截断并显示省略号。教室最多两行、教师最多一行，保留原有间距。卡片同时启用圆角裁剪。点击卡片仍可查看完整信息，存储的课程内容不变。

## 验证

- DevEco Studio 26 `assembleHap` 成功，新 HAP 已覆盖安装到 HarmonyOS 7 / API 26 手机模拟器。
- 七列、每节 56 vp 的实际课表中，检查了二节和三节课程、本周与非本周课程，以及滚动后的卡片。对完整可见卡片比较各文字节点边界：均在卡片内边距内、各行不重叠，教室和教师保留可见高度。截图复查通过。
- 验证保留设备原有课程和 Key；结束后返回当前周。

## 分享安装包与 Key

Key 来自使用者在应用内的输入，写入系统 `AssetStoreKit` 的 `SECRET` 字段；设备解锁时可访问，`SYNC_TYPE` 为 `NEVER`。普通 Preferences 只保存服务商名称。课表 JSON 备份只含学期、设置和课程，不包含 Key。

检查本次构建的 HAP 共 336 个条目：没有设备运行期间的凭据/Preferences 文件，也未发现 Key 或 Bearer 凭据样式的内置值。分享该安装包不会把本机保存的 Key 带给接收者；接收者需要输入自己的 Key。这项结论针对安装包及应用的课表导出，不包括整个设备数据镜像。
