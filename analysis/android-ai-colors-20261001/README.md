# Android AI 导入同名课程配色

AI 识别原先为每个上课时间生成独立记录，但没有提供配色；导入分析使用记录顺序为缺省颜色赋值，导致同一门课程的不同时间块颜色不同。

## 修复

- AI 识别按完整课程名称生成颜色。同名课程的星期、教师、教室或周次不同，也使用同一底色。
- AI 导入分析按课程名分组，追加导入沿用当前学期已有 AI 课程的颜色；颜色编号 `0` 同样保留。
- 系统导入继续使用原配色分支。
- 数据库从版本 1 升级到 2，只将同学期、同名 AI 课程统一为该组最早记录的颜色，覆盖 DeepSeek / OpenAI 来源。通过原来的 AI 来源备注限定修正范围，不要求重新识别。
- 使用显式 Room Migration；更新已保存的配色，不删除或重建课表。修正仅执行一次，升级后的手动配色不会在重启时被重置。

## 验证

- 回归测试覆盖不同上课时间、教师、教室、分段周次、不同返回顺序、颜色 0、追加导入复用颜色及系统导入分支。
- 原生测试使用独立数据库和原有表结构，标记旧版本 1 后打开新版 Room，验证 AI 配色统一、学期隔离，以及全部其他课程字段和学期记录保留；重新打开后验证手动改色不会再次被修正。
- 不使用用户的课表数据库或真实 API Key。
- `testDebugUnitTest`：141 项通过；Debug / 测试 APK 构建和 Lint 通过；Android 15 / API 35 迁移验证为 `OK (1 test)`。
